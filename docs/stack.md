# Stack

- **Framework**: Next.js 16.2.6 via `vinext` (Vite-based — NOT webpack)
- **Runtime**: React 19 with RSC via `@vitejs/plugin-rsc`
- **Styling**: Tailwind CSS v4
- **Language**: TypeScript 5
- **Build tool**: Vite 8
- **Linter**: oxlint
- **Formatter**: Prettier 3 (`singleQuote: true`, `semi: false`, `printWidth: 100`, `tabWidth: 2`)
- **Commit hooks**: Husky + commitlint (Conventional Commits)
- **Deploy target**: Cloudflare Workers via Wrangler
